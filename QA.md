# Forma: проверка

## Обновление 1.1

- В чистой копии комплекта на Linux / Node.js 22.23.3 прошли `npm ci`, проверка TypeScript, production-сборка и все 11 автоматических тестов. Команда `npm run launch` запустила собранный интерфейс и API.
- Проверены редактируемый адрес Ollama, нормализация адреса с `/api`, сохранение успешного подключения без перезапуска и отображение уже установленных моделей без скачивания.
- Проверены отдельные ошибки: сервер Forma не запущен, API вернул HTML, Ollama недоступна, выбранная модель не поддерживает инструменты.
- Автоматические тесты покрывают потоковый чат, изоляцию посетителей, экспорт, сохранение после перезапуска, ограничения облачного превью и Computer.
- Браузерный тест Computer использует настоящий Chromium: чтение страницы, подготовка и подтверждение ввода, точное содержимое формы, отклонение изменившегося действия, блокировка чувствительных полей и внутренних адресов.
- Интерактивно проверены задача с переходом на `https://example.com`, подтверждение, отказ, остановка, журнал, снимок страницы и восстановление текущей сессии после обновления страницы.
- Проверены desktop 1440×960 и mobile 375×812. На телефоне кнопка запуска Computer видна до прокрутки; горизонтального переполнения нет.
- Нативный запуск macOS и Windows в этой среде не проверен. Стартовые скрипты предусмотрены для всех трёх ОС; общая команда запуска проверяется на Linux.
- Реальная генерация пользовательской моделью не заявляется: тестовый сервер имитирует HTTP-протокол Ollama, а браузер и действия выполняются настоящим Chromium.

## Что проверяем

- Начальный экран: desktop 1440×900, mobile 375×812, отсутствие горизонтального скролла и перекрытия поля сообщения.
- Светлая и тёмная темы, повторное переключение, сохранение настроек.
- Боковое меню: сворачивание, открытие на телефоне, новый чат, поиск, модели, справка, настройки.
- Четыре стартовых подсказки, Enter / Shift+Enter, прикрепление текстового файла, удаление вложения, отказ для неподдерживаемого файла.
- Неподключённая Ollama: понятный статус, проверка, сохранение черновика при попытке отправить.
- Протокол Ollama на тестовом сервере: список моделей, потоковый ответ, контекст беседы, Markdown, код, повтор ответа, остановка, ошибочный ответ.
- История: сохранение после перезагрузки, поиск по содержимому, переименование, экспорт Markdown, отмена удаления, подтверждённое удаление.
- Модели: загрузка с прогрессом, выбор установленной модели, ошибка имени модели, отмена ожидания.
- Изоляция данных между посетителями, отсутствие содержимого чатов в логах, отсутствие клиентских ключей.
- Настройки: температура, контекст, системная инструкция, проверка фактических параметров тестового запроса.
- Проверка типов и production-сборка.

## Границы проверки

`tests/ollama-fixture.mjs` имитирует только документированный HTTP-протокол Ollama. Он не генерирует настоящие ответы и не должен работать в пользовательском превью. Фактическая генерация и загрузка весов на пользовательском компьютере требуют установленной Ollama, модели и достаточного оборудования. Эти действия здесь не подтверждены.

## Зависимости

Аудит npm сообщил о 9 предупреждениях в цепочке инструментов сборки Tailwind 3 / PostCSS (5 high, 4 moderate), для которых автоматическое исправление без смены стека не предложено. `npm audit fix` выполнен. Пользовательский текст не передаётся этим парсерам, и они не обрабатывают запросы чата в production. Для публичного продукта потребуется отдельный аудит и обновление инструментов сборки; отсутствие предупреждений безопасности не заявляется.

## Результаты

- TypeScript и production-сборка проходят.
- Проверены светлая и тёмная темы на 1440×900 и 375×812; горизонтального переполнения нет. Поле сообщения и основные действия помещаются на экране.
- На тестовом сервере получены потоковые ответы, подтверждена передача истории (2 и 4 сообщения с системной инструкцией), вложения, температуры 0.6 и контекста 4096.
- Подтверждены остановка с сохранением частичного ответа, повторная генерация, ошибка модели, сохранение после перезагрузки, поиск по тексту вложения, переименование, отмена и подтверждение удаления.
- Экспорт скачивает Markdown с правильным содержимым, включая пометку прерванного ответа. Копирование сообщения и кода проверено через буфер обмена Chromium.
- Загрузка модели проверена на протокольном тестовом сервере: прогресс, успешное завершение, ошибка имени и отмена.
- Отдельный посетитель получает пустую историю и 404 при обращении к чужому чату. Пользовательские сообщения отсутствуют в журналах HTTP-запросов.
- Проверены нештатные сценарии: отправка без Ollama сохраняет черновик; неподдерживаемый файл отклоняется; прерванная генерация не оставляет вечный индикатор.
- При дополнительном проходе по обычным действиям проверены боковое меню, подсказки, справка, настройки, файл и модель. Ошибок JavaScript не обнаружено.
- Исправлены гонка при остановке ответа, закрытие контекстного меню и контраст текста в полях.
