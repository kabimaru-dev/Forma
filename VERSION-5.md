# Forma — версия 5

Основа: Forma-thinking-effort-per-level.zip. Селектор: утверждённый макет forma_mode_selector_v6.6.html.

Уровни: Light → Standard → Terra → Harmony. В YAML сохранены прежние ключи minimal / moderate / intensive / extreme.
Reasoning: Minimal, Low, Medium, High, Extra, Max, Ultra. Ключ Extra остаётся extra_high для совместимости.
Две отдельные овальные кнопки рядом с отправкой открывают панель. Строка уровня открывает боковые настройки Reasoning / Speed / Model. Перенесены цвета, заливка, тёмный бегунок, движущиеся стрелки и анимации открытия/закрытия.

Anime-Sakura — публичное имя стандартного маршрута levels в config/modes.yaml. Model 02–07 — публичные псевдонимы: реальные имена задаются в model_choices, не передаются через /api/modes. При выборе такого псевдонима отправка использует его model; блокировки уровня, Reasoning и Speed продолжают действовать.

Если уже есть config/modes.yaml, сохраните назначения и добавьте недостающие minimal/ultra под models каждого уровня, а также блок model_choices из примера. Без настройки новые варианты отключены; выдуманные модели не используются. Terra и Harmony по умолчанию остаются заблокированными прежним конфигом.

Настройки генерации по-прежнему доступны в общих настройках приложения. Данные, схема и настройки БД не изменены.
