# Forma · Режимы

В ZIP готова кнопка с уровнями **Core / Plus / Pro / Ultra**. Core и Plus включены; Pro и Ultra оставлены на будущее.

- **Reasoning:** Low, Medium, High, Extra High, Max.
- **Speed:** Normal, Fast.
- Для каждого сочетания уровня, Reasoning и Speed назначается отдельная модель Ollama.
- Откройте `config/modes.yaml`, найдите нужную комбинацию и впишите идентификатор установленной в Ollama модели:

```yaml
levels:
  core:
    enabled: true
    models:
      medium:
        normal: "your-installed-model:tag"
        fast: "another-installed-model:tag"
```

**Важно:** это только фрагмент структуры, не заменяйте им весь файл! Редактируйте готовые строки в `config/modes.yaml`. Неназначенная модель = режим не готов; Forma покажет понятную ошибку. Не добавляйте новых уровней в браузере: перечень задан программой. Скорость обозначает ваше предпочтение, а не гарантирует ускорение самой модели.

`config/modes.yaml` исключён из Git через `.gitignore`, чтобы при публикации репозитория не раскрывать назначения. Образец без реальных имён хранится в `config/modes.example.yaml`. Если локальный файл отсутствует, `npm run launch` автоматически создаст его из образца. Изменения YAML применяются к **следующей отправке** без перезапуска сервера.

В обычном режиме браузер отправляет только идентификатор вроде `forma:core:medium:normal`; сервер подставляет реальную модель перед вызовом Ollama. История сообщений также сохраняет псевдоним режима. Это скрывает имена в меню и истории, **но не является защитой от администратора самого сервера**, и список установленных моделей всё ещё доступен в разделе «Модели» в ручном режиме.

Ручной выбор Ollama не удалён: меню режима → «Ручной выбор». Название выбранной вручную модели видно, как и прежде.

Конфигурация использует простой YAML с вложенными mapping-полями, отступами по 2 пробела, строками и булевыми значениями. Сложные конструкции YAML (якоря, массивы, многострочные значения) не предусмотрены.

Запуск — как раньше: `npm run launch` или `Start Forma.command`. Проект требует Node.js 22+ и работающую Ollama.
