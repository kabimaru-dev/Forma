# Forma 1.1

Полный локальный проект: React-интерфейс, Express-сервер, история SQLite, подключение Ollama и Computer с отдельным Chromium. В архив входят исходники и готовая сборка `dist`; одного `dist/public` для работы недостаточно.

## Быстрый запуск: macOS, Linux, Windows

Нужен Node.js 22 или новее. Ollama не требуется переустанавливать: используйте уже работающую установку.

1. Распакуйте весь архив.
2. Откройте терминал в папке `forma`.
3. Выполните:

```sh
npm run launch
```

Скрипт установит зависимости, если их ещё нет, и запустит полный сервер. Откройте `http://127.0.0.1:5000`. Если меняли исходники, перед запуском выполните `npm run build`.

Дополнительные ярлыки:

- macOS: `Start Forma.command`; если права на запуск потерялись, выполните `chmod +x "Start Forma.command"` и затем `./"Start Forma.command"`.
- Linux: `sh start-forma.sh`.
- Windows: `start-forma.bat`.

Терминал должен оставаться открытым. Остановка: Ctrl+C. Команды не устанавливают Ollama и не скачивают модели.

## Подключение уже установленных моделей

В Forma откройте «Настройки → Подключение», укажите `http://127.0.0.1:11434` и нажмите «Проверить и сохранить». Если Ollama работает по другому адресу, укажите его в том же поле. Адрес сохранится в SQLite после успешной проверки без перезапуска приложения.

Установите нужные модели через Ollama (`ollama pull имя-модели`), затем назначьте их уровням в `config/modes.yaml`. Вкладки «Модели» в интерфейсе больше нет.

Предварительный адрес также можно задать в `.env`: скопируйте `.env.example` в `.env` и измените `OLLAMA_HOST` или `OLLAMA_URL`. Настройка из интерфейса имеет приоритет над окружением.

В Docker `localhost` относится к контейнеру, а не к вашему компьютеру. На macOS/Windows обычно нужен адрес `http://host.docker.internal:11434`; на Linux способ доступа к хосту зависит от настройки Docker. Сам проект не требует Docker.

## Если подключение не работает

```sh
npm run doctor
```

Диагностика отдельно проверяет Ollama и сервер Forma. Выводит адрес, HTTP-статус и имена установленных моделей, не содержимое переписки.

- **Сервер Forma недоступен:** запущен один фронтенд или отсутствует сервер. Запустите `npm run launch` в корне полного проекта.
- **Вместо API пришёл HTML:** открыта статическая папка или API направлен на Vite без backend. Пользуйтесь единым адресом `http://127.0.0.1:5000`.
- **ECONNREFUSED:** адрес Ollama не доступен серверу Forma. Проверьте хост и порт, а не переустанавливайте модели.
- **ENOTFOUND:** ошибочное имя хоста.
- **Ollama подключена, но моделей нет:** выбран не тот экземпляр Ollama или другой компьютер.
- **Облачное превью:** не может увидеть вашу домашнюю Ollama автоматически. `FORMA_PREVIEW=true` запрещает менять серверные адреса и запускать Computer в превью. В локальном проекте оставьте `FORMA_PREVIEW=false`.

## Computer: подготовка запуска

Для отдельного браузера один раз выполните:

```sh
npm run setup:computer
```

Linux при недостающих системных библиотеках:

```sh
npm run setup:computer:linux
```

Подготовка скачивает Chromium, а не веса модели. В Computer выберите установленную модель с поддержкой вызовов инструментов; используется [документированный цикл tool calling Ollama](https://docs.ollama.com/capabilities/tool-calling).

Навигация, нажатия и ввод текста показывают точное действие и требуют отдельного подтверждения. Пароли не вводятся, загрузки файлов в браузере отключены, внутренние сетевые адреса запрещены, команды ОС не выполняются. Это базовый браузерный агент, а не полная копия сервиса Perplexity Computer.

Сессия и журнал текущей задачи Computer живут в памяти сервера; переживают обновление страницы, но не перезапуск сервера. Журнал можно экспортировать до закрытия. После 45 минут без обращений браузер закрывается. Содержимое сайтов может быть недостоверным или вредоносным; проверяйте действия перед разрешением. Изолированный профиль браузера не является виртуальной машиной.

## Разработка

```sh
npm ci
npm run dev
```

Одна команда запускает Vite и Express вместе на порту 5000.

Отдельный фронтенд допустим только вместе с сервером Forma. На стандартных Vite-портах 5173/4173 API автоматически направляется на локальный порт 5000. Для другого адреса задайте `VITE_API_BASE` перед сборкой. Скачанные сборки, открытые на localhost, не используют облачный прокси превью.

```sh
npm run check
npm run build
npm start
npm test
```

## Данные и ограничения

- История и настройки хранятся в `data.db`. При обновлении заменяйте файлы проекта, но сохраните вашу базу и `.env`. Для резервной копии остановите Forma и скопируйте базу.
- Приложение рассчитано на локальное использование одним человеком. По умолчанию слушает только `127.0.0.1`. Не публикуйте его или Ollama в интернет; входа по паролю здесь нет.
- Локальные модели обрабатывают запросы на вашем оборудовании; облачные модели Ollama у провайдера. Обмен выполняется через [`/api/chat`](https://docs.ollama.com/api/chat); новая загрузка через [`/api/pull`](https://docs.ollama.com/api/pull).
- Текстовые вложения до 100 КБ, сообщения с вложением до 100 000 символов. Изображения/PDF/голос пока не поддерживаются.
- Контекст может обрезаться Ollama при достижении предела модели; автоматического резюмирования нет.
- Содержимое чатов не записывается в HTTP-логи. HTML в ответах модели не исполняется. Голосовой ввод, ОС-инструменты и доступ к пользовательскому браузеру не добавлены.
- Шрифт загружается через Google Fonts; без сети применяется запасной шрифт.
- Аудит инструментов сборки и границы тестирования описаны в `QA.md`.

## Состав архива

`client/`, `server/`, `shared/`, `script/`, `tests/`, `dist/`, `package.json`, `package-lock.json`, конфигурации TypeScript/Vite/Tailwind, `.env.example` и стартовые файлы для трёх систем. Личная база, ключи, `.env`, `node_modules` и тестовая история в архив не входят.
