# Как запустить Forma

Распакуйте весь архив. Нужен Node.js 22 или новее; вашу Ollama переустанавливать не нужно.

В терминале перейдите в папку `forma` и выполните:

```sh
npm run launch
```

Откройте `http://127.0.0.1:5000`, затем «Настройки → Подключение»:

```text
http://127.0.0.1:11434
```

Нажмите «Проверить и сохранить». Установленные модели появятся в разделе «Модели» без повторного скачивания.

Для Computer один раз выполните:

```sh
npm run setup:computer
```

На Linux при недостающих библиотеках: `npm run setup:computer:linux`.

Для диагностики: `npm run doctor`. Более подробные инструкции и ограничения находятся в `README.md`.

Не запускайте только `dist/public`: это интерфейс без сервера. Не переносите старую сборку из облачного превью поверх этого проекта.
